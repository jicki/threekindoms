# v0.3.9 · 地图情报、手柄与电脑好战

## 地图与侦察

- 君主列传新局使用战役规则修订 7。平面与立体地图共用城签规则。城名按势力着色，无主据点另标「无主」，孙策使用更易与袁术区分的橙色。
- 敌城兵力与武将详情经侦察后可见。侦察当月和随后三个月有效，更换所属势力后须重新侦察。己方和无主据点可直接查看。城市面板在有情报时显示武将数、正规军、预备兵等详情，市集显示米的买入和卖出价。
- 桌面用鼠标出阵、运输和侦察时，可直接点亮起的据点，或点「选择列表」。切换键盘或手柄会显示可聚焦的列表，手机可继续从列表或地图选城。
- 桌面可点势力列表中的势力突出显示其领地，也可收起右侧消息。突出显示与全图势力开关独立，消息折叠偏好会保存。

## 手柄

- 外交目标列表可用方向键和摇杆移动焦点，用确定键或向右展开，向左或取消逐层收起。
- 「☰ 系统 → 手柄记录快捷键」可为记录进度、读取记录、快捷存档和快捷读档绑定按键。默认未绑定，同一个键只能分给一个记录操作。战略地图会提示已绑定的按键，选城时会提示方向键和确定键。快捷键在己方战略回合生效，并遵守现有存档限制与确认流程。
- 记录编辑支持焦点导航、调整数值和选项、确认及取消。离开时仍会确认放弃未写回的改动。

## 电脑好战

默认关闭。开启后跟随战役的 LEVEL 1 至 3，效果只作用于电脑势力。

| 档位 | 额外行动 |
| --- | --- |
| 初级 | 搜将的基础检查从 10% 提高到 13%。每个电脑回合额外尝试补兵一次，目标为 650 兵。出兵门槛采用对应难度的常规规则 |
| 中级 | 搜将检查为 17%。额外补兵一次，目标为 800 兵。选择攻击目标时更看重守军实际兵力 |
| 上级 | 搜将检查为 21%。额外补兵最多两次，目标为满编。增加一张命令书的战略行动额度。新增招募武将忠诚可提高 10，增益封顶 95。开发额外增加 3 点基础收益。每次常规税收或收粮增幅为 20%，每据点每次最多增加 250 |

额外补兵先用预备兵，然后按每 20 金征 100 人计费，余额留在城内。关隘继续从可供给的邻接据点调配。初、中级也会优先照顾灾害防备与较弱的土地或产业。三档沿用各自的战场伤害和计策规则。

- 郭嘉获得独立立绘、头像、四种表情及 16 格骑马动作，应用于战场行军、白兵和单挑。徐晃获得独立头像和双手持斧立绘。新增素材固化在 [静态素材包 2](https://github.com/jicki/threekindoms/releases/tag/assets-2)。
