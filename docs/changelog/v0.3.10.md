# v0.3.10 · 郭嘉单挑动作重制

## 单挑画面

- 郭嘉的行军、白兵和单挑分别读取各自适用的动作。单挑优先使用重制帧，素材读取失败时回退到原有个人单挑动作。此次延续 v0.3.9 的立绘、头像、表情和行军格图。
- 以徐晃等现有骑乘武将为参照，重新调整骑手头身与马匹比例。站立时的有效高度由 92 像素提高到约 112 像素，显示高度按新的体型校准。帧表用最近邻采样保留像素边缘，站姿和出招以马蹄为基线，攻击效果以各帧剑尖定位。
- 重制动作涵盖待机、骑行、出剑、收招、受击、闪避、挑衅及基础退场。掉头、落马和败北特写沿用郭嘉完整的个人演出。左右站位共用相同的原始朝向素材，按对阵方向镜像显示。

## 兼容与部署

原版、君主列传及已有存档沿用各自的战斗和装备规则。此版本只更新单挑演出和素材读取，不需要迁移存档。素材包发布为 [assets-3](https://github.com/jicki/threekindoms/releases/tag/assets-3)。桌面安装包和 SHA-256 校验清单见 [v0.3.10 Release](https://github.com/jicki/threekindoms/releases/tag/v0.3.10)。

README 保留当前入口、规则及部署方法，移除了已退役剧本的技能清单和历史适配状态说明。
