# 出阵与动作预览、标题读档修复

## 出阵与人物志

- 在选定出阵目标后的选将界面展示进场方向、内外城门方位、外围地形和预计天气。「查看战场布阵」展开按实战布局绘制的俯视图。空城直接提示可占领。
- 援军预览沿用当前战役出援条件。先侦察目标才能查看守军，先侦察对应盟城才能查看该城的潜在援军数量。实际出援随开战时的兵粮和外交状态计算。
- 「人物志 → 武将 → 动作预览」可单次播放行军、白兵攻击、单挑攻击并左右换向。白兵与单挑沿用实战的当前武器动作，并可预览弓的松弦和扇的挥击。面板列出装备、兵种和当前生效的被动。

## 修复与兼容

- 连续点击「继续记录」只启动一次。普通读档初始化失败会回到标题，原记录可重试。玩家确认替换已中断的战斗后，等新战役成功初始化才移除已确认的中断记录。确认期间若中断记录被另一标签页替换，玩家可在标题重新选择。
- 手机上即使只有一份普通档或快捷档，只要标题优先显示「继续上次」，玩家也可以用「读取记录」选择保存的档案。
- 根地址保留声音偏好。显式 `?mute` 仅让带该参数的页面静音。
- 单挑特写素材遇到暂时的加载故障时，本场使用现有动作，后续单挑会重试。已载入的素材继续复用。
- 开局及统一结局按实际规则显示城数。当前君主列传为 34 城及 5 处关隘，原版仍称「三十州」。
- 预览沿用原版、君主列传及既有存档保存的规则。存档格式、素材包版本和战斗数值保持原样。

## 验证

- 网页回归覆盖原版与君主列传开局、旧战役、普通档和快捷档、跨标签页中断记录、手机触控、白兵及单挑换装和特写素材重试。
- 规则与网页 Node 测试共 402 项经复验通过。服务端 Python 测试通过 29 项，另有 1 项因需要 root 验证文件所有权而跳过。
