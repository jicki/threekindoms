# 2026-11-21 宛城外营守军与战场缩放栏

- 桌面 3D 战场把「－／＋／全图」放到右下角，贴近旋转和选将工具。窄窗口上下排列，小地图随工具栏上移。布阵完成键在右上方。
- 宛城外营的电脑守军会判断附近敌军、可达路径、兵力、体力和剩余机动力。只遇到可应付的近敌时，营格守军可短距离出击。若有多支敌军逼近，营格守军留守，有其他守军驻营时可派营侧部将迎击。失去接战机会且营格空出时，外营守军会尝试回营。
- 迎击遵循实际地形和通行规则。攻方占领前阵后仍按现有规则解锁城门。该调整用于启用新版攻城规则的君主列传战场布局修订 10，中断恢复按存档内的布局、营地状态和站位继续。

使用宛城三条来路和相同的随机种子，比较了 72 场电脑对战。各组均接敌，每组 12 场。3、6、10 将攻 3 将时，攻方胜场分别从 4、7、6 场变为 0、7、9 场。
