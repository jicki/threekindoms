# 2026-11-21 君主列传修订 13 · 地域战场

君主列传的 39 处战场按地势重新布置。城门、街区、主堡、河岸及关轴固定在当地地图上，发兵城市决定攻方从哪一侧布阵、哪些门是最近的目标。洛阳、长安容纳三条进城路线，常规城市至少有两条通往不同外门的路线。五处峡谷关隘采用沿谷进攻和绕行栈道两种走法。地图使用地域地貌作为游戏设计依据，城墙、道路和据点间距按战术玩法作了取舍。

洛阳的布局参考汉魏故城的城垣和里坊，以及北侧邙山、南侧洛水的方位。襄阳以汉水南岸和沿江城防为基础。剑阁以剑门山断崖和蜀道栈阁为基础。夷洲采用史籍中的跨海叙事，具体湾岸、港口和登陆点为游戏里的示意。 [国家发改委 · 汉魏洛阳故城](https://www.ndrc.gov.cn/xwdt/ztzl/dyhgjwhgy/202209/t20220921_1335876_ext.html) · [湖北省文化和旅游厅 · 襄阳古城](https://wlt.hubei.gov.cn/bmdt/mtjj/202609/t20260916_6015364.shtml) · [广元市文化广电旅游局 · 剑门关](https://swglj.cngy.gov.cn/mshow/036eb25d2e924faab98be89677543391.html) · [《三国志·吴主传》](https://www.shidianguji.com/book/LS0004/chapter/1j7fnuwyvj9yz_302)

## 通行与攻守

| 地形或设施 | 战场行为 |
| --- | --- |
| 官道和侧路 | 每格少耗 1 点机动力，最低 1 点。部队占据的格子仍会阻塞移动。 |
| 木桥与浅滩 | 架桥段按平地行军，白兵使用桥头布局。浅滩可涉水，保留水地天气和水计判定。 |
| 深水、深海和水壕 | 陆军无法进入。跨海部队从已登陆的阵区开局。 |
| 断崖与栈道 | 断崖不可通行并阻隔计策。栈道可越过外关，600 兵起取消道路的 1 点机动力减免。内关仍需突破。 |
| 城墙、城门与街坊 | 城墙和房舍挡住移动与计策。攻方突破封闭城门多耗 2 点机动力，破门状态持续并且不可撤销。守军仍可从门口迎击近敌。 |
| 宛城前阵 | 总大将从外营出发，同批部队按兵力分守外营与城墙。攻方占住前阵才可破门，双方总大将的战败判定继续生效。 |
| 前哨 | 有兵力的单位驻守时，次日为本方增加 2 点机动力。 |

电脑攻方使用同一套通行和寻路规则，会绕水岸、断崖及建筑，按可达路线选择城门。宛城先向前阵推进。守军会增援受到威胁的城门，对进入外城的部队优先接战，在宛城可就近防守营地或回援主城。自动结算沿用已有抽象战力规则，并读取当地战场水域供水战被动判断。

出阵预览显示地貌、城门、具体布阵边界和可选路线。手机平面战场在海战开场同时纳入两处登陆区，点「主登陆滩」或「侧翼小湾」可定位。宛城守方可切换「外营驻地」和「城内守备」。开战后移动照常计算路径和机动力。3D、平面底图、小地图和按地形查看共用道路及设施数据。白兵按交战地格选择桥头、浅滩、栈道、外营、街巷或滩头的机动带，保留阵法起始格。

## 存档与回归

### 概念图细化

洛阳的南门增加墩台和低墙围合的瓮城，石铺主街延伸到偏置宫院，宫殿增加高台、台阶和红柱，街坊单元增加院墙。剑阁采用连续起伏的岩壁、带护栏的抬高栈道和重檐关楼，默认镜头同时纳入主关和绕行路线。襄阳增加浅滩石洲与临水栈桥，夷洲增加码头和停泊船只，宛城的前阵以营帐和军旗显示。桌面布阵定位按钮移到系统按钮下方，手机沿用顶部安全区布局。

新增构件和高差只用于取景、显示和拾取，路线、碰撞规则、机动力和存档数据仍使用修订 13 的格子。

君主列传新开局使用战役修订 13、城防布局修订 6。旧战略存档以原修订打开，主动升级只影响之后开打的战斗。原版及自定义剧本沿用既有地图。中断记录保存布局版本、部署位置和城门，宛城额外保存前阵解锁状态。恢复时校验单位地格和门状态，遇到无效记录可以保留原记录。

路线回归覆盖 39 处战场和 146 条来路，并检查深水、断崖、兵力差异、桥面与浅滩的天气判定。浏览器验证桌面三维城防、手机两处登陆区的真实触控、地形阻挡及旧版战场和战斗中断恢复。

平衡复测对同一来路使用相同随机种子。每将 700 兵、90 体力、70 武力和 60 智力，双方粮草充足。每组覆盖 146 条来路，共 584 场电脑实战。
