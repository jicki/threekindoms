# 2026-11-21 君主列传修订 14 · 城池扩建

战役修订 14 使用城防布局修订 7。调整覆盖 34 处城池和 5 处峡谷关卡，共 146 条来路。以下尺寸以城池或关卡外廓为准，缺角以内的面积按实际格计算。

| 据点 | 原外廓 | 新外廓 | 变化 |
| --- | --- | --- | --- |
| 洛阳 | 17×13 | 23×17 | 宫城外留回环街巷，内城增加西门 |
| 长安 | 15×15 | 21×19 | 扩充宫城和街坊，内外城之间可换防 |
| 兖州 | 11×9 | 17×13 | 增加后寨和内街，南岸保留桥、浅滩和集结场地 |
| 豫州 | 13×7 | 19×11 | 增加三门内城，外城主街可绕行 |
| 宛城 | 11×9 | 17×13 | 外营、外城、内寨形成纵深，总大将在内寨 |
| 剑阁 | 7×15 | 7×19 | 加深隘口，靠崖栈道仍可绕外关 |

- 城内街区以主街、横巷和绕内墙的通路连接，主街可供两列部队通行。每座外门都有到主堡的城内路径，房舍占地从布阵格中排除。34 处城池在全图的实际占地约为 9.7% 至 22.2%。
- 都城和 14 处重点城池设有三门内城。其余城池保留便于展开的单层城防。守方按主堡、各方向城门及内街分区站位，靠近来敌方向的门优先布防。
- 宛城由部将驻守外营。部将在外营失利时攻城继续，总大将战败的结算规则照常生效。攻方占领前阵后才能破门。宛城河道采用连续水格，桥头接到平缓地面。
- 18 处天然河道全部验证四向连通。河岸向外墙外侧布置，桥和浅滩跨河，桥头预留上岸地格。向水城进攻时，渡口外留有集结位置。五处峡谷关卡沿谷道加深，谷底宽度仍按各关地形配置，栈道入口留在可达范围内。
- 战场米店靠近补给来路，武器店靠近进城路线，医馆优先安排在另一条来路旁。店铺之间至少隔四格，并避开城墙、桥面、布阵区、前哨和外营。所有原有服务与货架保留，各店在破门前也可从城外抵达。
- 扩建后将陆路集结点移近城门，降低开局整军的行军耗时。守军仍可借墙、门和纵深消耗攻方。手机保留布阵区定位与触控选人、换位。
