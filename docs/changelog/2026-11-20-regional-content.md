## 存档与素材

- 君主列传新开局使用修订 10。旧记录照常读取，可在己方战略回合通过「系统 → 记录 → 升级当前战役」取得新角色和地方装备。升级保留既有人物与装备编号，顺延重叠的旧分身编号并更新引用。中断战斗沿用记录建立时的规则。
- 新资产位于 `hd2d-mvp/assets/regional/`。内置 imagegen 以三行三列、汉末冠服、像素风胸像的规格制作人物图集，并以三行三列、透明底、清晰轮廓的规格制作刀扇弓图集，再裁切为 WebP。小图随代码分发，沿用当前素材包锁定版本。

## 回归验证

265 项规则测试和 50 项网页相关回归经复验通过，覆盖寻访、被动、地方货架、电脑购物、军中购买、手机触控、记录编辑器、旧档升级及中断恢复。17 张图片均已验证进入 Docker 构建上下文。
