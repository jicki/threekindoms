# 单挑人物比例、倒地和结算头像

- 个人单挑动作、通用动作、换装动作和编辑器上传的格图按待机帧中人物与坐骑的实体高度统一缩放。保留武器、头饰的轮廓和个人素材的美术比例。格图的待机、行走、攻击和转向帧对齐接地位置。
- 黄祖与吕布同场时使用一致的骑乘尺度。落马后的身体按人物大小显示，倒地以身体的位置接地。蔡瑁等使用格图的将领直接切到同一素材的倒地帧，被俘时护卫按实际人物轮廓站位。
- 郭嘉的重制动作和旧个人动作各自成套使用。重制图读取失败时使用旧个人动作，避免在转向和落马时切换装束。
- 忧容解码完成后更新结算头像。阵亡、被俘和退却仍由原有规则决定，存档数据格式保持一致。

核对了 244 份动作素材和 54 张备用立姿。网页回归覆盖左右阵亡、俘虏与退却、手机弓扇、原版换装、郭嘉特写回退和延迟加载忧容。
