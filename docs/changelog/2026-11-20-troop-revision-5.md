# 2026-11-20 · 君主列传兵种修订 5 与构建修复

对应提交 [`50037a4`](https://github.com/jicki/threekindoms/commit/50037a4037c342aa0ec57aae30b5600061555ec7)。

- 君主列传修订 5 为内置的 265 名人物配置主兵种。普通武将默认带普通步兵，新增 16 名按角色定位分配的武将。城市名单、人物资料及战场详情支持兵种标记，即使武将当前兵力为零也会显示。
- 修订 4 的未配置武将显示「混编」。原版及现有存档沿用其编队修订。需要新编队时，可在己方战略回合手动升级当前战役。
- Docker 使用独立清单和锁文件，安装 Three.js、马善政和思源宋体。依赖安装不再出现 `rimraf`、`inflight` 和 `glob` 三条弃用警告。
- 桌面版通过包内单挑素材索引加载无损 WebP 动作，修复打包依赖替换源码片段的问题。浏览器继续加载对应的 PNG 动作。

提交前通过了 611 项核心测试和 9 项相关浏览器用例，以及 Docker 构建与启动、macOS 包试运行和 Windows x64 ZIP 完整性检查。

兵种分配和进阶规则见[主辅兵种编队](../../README.md#主辅兵种编队)。
