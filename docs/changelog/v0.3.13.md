# v0.3.13 · 地域战场、整队布阵与开场加载优化

## 战场与攻城

- 君主列传新开局使用战役修订 17，涵盖 39 处地域战场和 146 条来路。重新设计城郊、河道、桥梁、浅滩和山地道路。洛阳、长安等重点城池扩大外城和内院，多条道路接不同城门。峡谷关隘按谷道、栈道布防，夷洲保留两个登陆点。 [地域战场](2026-11-21-regional-battlefields.md) · [城池扩建](2026-11-21-expanded-wards.md)
- 陆路攻军按来路整队进入一个角区，布阵时可整队换角。守军按主堡、城门和街区布防。宛城外营守军根据兵力、路径和附近敌军决定出击、留守或回营。并州西侧来路补齐集结地和桥头衔接，米店、武器店及医馆按实际通路布置。 [整队布阵](2026-11-21-army-deployment-and-zoom.md) · [宛城外营](2026-11-21-camp-defense-and-zoom-toolbar.md)
- 战斗开场镜头聚焦己方可控武将。全图可用 Esc 或点地图退出，桌面触摸板支持连续缩放，手机可双指缩放和拖动。选定计略后，可点选或悬停不可施计的敌将查看距离、城墙或街区建筑等限制。 [计略目标](2026-11-21-strategy-target-feedback.md)

## 城市、人物和加载

- 城市命令分为「城、军、仓、町、谋」。调遣直接在地图选择可接收武将的邻城，选将时显示余位。无主城按原版公式积累岁入，电脑会考虑派部队占领空城。 [城市命令与电脑扩张](2026-11-21-battle-approaches.md#城市与电脑)
- 更新郭嘉、张飞、杨修等武将的立绘，重绘郭嘉行军与单挑动作、关羽持刀行军。单挑按骑手和坐骑的实际轮廓对齐比例，修复落马接地、左右结算动作与头像更新。 [立绘和动作](2026-11-21-battle-approaches.md#素材) · [单挑演出](2026-11-20-duel-proportions.md)
- 14 张地表和岩壁材质使用轻量 WebP，大战场按地格控制合成贴图的像素量。原版 3D 跳过整张历史手绘地图。战场素材在淡出期间并行加载，战斗音乐提前准备，慢请求不阻塞布阵。本机冷缓存兖州样本中，桌面 3D 从 1.87 秒降至 1.63 秒，手机平面模拟从 1.13 秒降至 0.97 秒。 [开场测量与回退](2026-11-21-battle-entry-loading.md)
- 修复计略次数按 Enter 确认、手机城池折叠面板数字裁切和 WebGL 初始化失败时的黑屏提示。

## 存档与下载

原版沿用原规则。君主列传旧战役可在己方战略回合主动升级，已中断的战斗按记录里的地图、站位和城门状态续玩。新立绘、动作和轻量贴图随代码分发，构建继续使用锁定的 [assets-3 素材包](https://github.com/jicki/threekindoms/releases/tag/assets-3)。

桌面包提供 macOS Apple 芯片和 Intel 的 DMG，以及 Windows x64 ZIP。[发布页](https://github.com/jicki/threekindoms/releases/tag/v0.3.13)附 SHA-256 校验清单。
