# 君主列传人物被动

战役规则修订 8 为全体 265 名在籍武将各分配一项被动。65 名武将和谋臣拥有独立效果，其余按剧本的初始武力、智力和人物编号分配 17 种通用模板，包括尚未登场的人物。武将成长后保留原先分配。重名人物括号内是武将编号。

人物资料显示实际生效的被动。新开局默认使用修订 8。已有记录和中断战斗按保存的修订使用原有被动，在己方战略回合可选择「升级当前战役」。原版使用原有规则。自定义扩展剧本启用新版战场后，管理员可选通用模板覆盖自动分配。

命中修正按判定阈值叠加，实际概率仍由随机表决定。白兵的兵队普攻加成按攻击方式、兵类和回合结算。单挑加伤只作用于命中且已有伤害的招式，最终伤害最多为 127。战场减免机动力最低为 1，突破城门另付消耗。势力级奖励见 [君主被动](../../README.md#君主被动与专属武器)。
