# 特色兵队动作素材

`special-soldier`、`special-archer`、`special-cavalry` 分别为重甲重盾兵、弩兵和普通轻骑；`unit-` 开头的十一套动作分别对应普通／重甲步兵、普通／重甲枪兵、单锤／双锤兵、普通盾兵、重甲骑兵、皇家骑兵、普通弓兵和骑射兵。十四套素材均由内置 imagegen 重新绘制，不是原版或 PS 版素材；PNG 是游戏使用的透明动作条，JSON 保存帧名、尺寸与动作节奏。

生成时以三国时期的短剑、长枪、锤、盾、弓弩和骑兵为主题，分别描述普通与重甲装备、双锤、皇家铠饰或骑射动作；侧面动作为历史题材 HD-2D 像素风格，包含待机、行走、奔跑、攻击、受伤、倒下和庆祝。弓兵、弩兵和骑射兵包含拉弓／弩和发射帧；骑射兵的 `volley` 片段在发射帧触发箭矢。侧面生成图经项目的 `tools/slice_troop_frames.py` 转为游戏动作条，普通盾兵经 imagegen 去除生成时残留的背景。

各兵种的 `-turn` PNG 和 JSON 是以对应侧面素材为参照，通过 imagegen 新绘的正面、背面动作条；每个方向有待机、四帧行走、蓄力、攻击和受伤，远程兵种另有发射事件。生成图按人物透明区域切片、以脚底或马身对齐，并按侧面素材的人物高度缩放。素材在参战前按需加载；转向文件缺失时使用侧面动作，侧面文件缺失时使用普通兵队素材。
